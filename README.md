# 모이모 (moimo)

졸업전시용 웹사이트입니다.
전시장 컴퓨터 앞에 선 방문자가 **이름을 입력하면 자기만의 캐릭터가 태어나고,
그 캐릭터와 함께 사진을 찍어 QR코드로 가져갈 수 있습니다.**

## 1. 실행하기

### 처음 한 번만 (준비)

컴퓨터에 [Node.js](https://nodejs.org) 가 설치되어 있어야 합니다.
(설치되어 있는지 모르겠다면 터미널에 `node -v` 를 쳐보세요. 숫자가 나오면 있는 겁니다.)

터미널에서 이 폴더로 들어간 뒤:

```bash
npm install
```

한 번만 하면 됩니다. 필요한 재료들을 알아서 전부 받아옵니다. (1~2분)

### 매번 실행할 때

```bash
npm run dev
```

이 명령 하나로 **화면**과 **사진 창고** 두 가지가 동시에 켜집니다.
그리고 브라우저에서 아래 주소를 엽니다.

> **http://localhost:5173**

끝내고 싶을 땐 터미널에서 `Ctrl + C` 를 누르세요.

## 2. 화면이 어떻게 흘러가나요

```
   이름 입력  →  캐릭터 등장  →  같이 사진 찍기  →  결과 + QR코드
      /          /character        /capture           /result
                                                         │
                                                         ↓
                                              모두의 모이모 갤러리
                                                    /gallery
```

| 주소 | 화면 | 설명 |
| --- | --- | --- |
| `/` | 이름 입력 | 전시장에서 계속 띄워둘 첫 화면 |
| `/character` | 캐릭터 등장 | 이름으로 태어난 캐릭터를 보여줌 |
| `/capture` | 사진 찍기 | 웹캠 + 캐릭터, 3·2·1 세고 찰칵 |
| `/result` | 결과 | 완성된 사진 + QR코드. 90초 뒤 자동으로 처음으로 |
| `/gallery` | 공개 갤러리 | 다녀간 사람들의 사진이 모이는 곳 |
| `/p/사진번호` | 사진 한 장 | QR로 들어온 방문자가 보는 화면 (저장 버튼) |

**같은 이름을 넣으면 항상 같은 캐릭터가 나옵니다.** 이름이 곧 그 사람의 모습이 되는 구조예요.

## 3. 내가 그린 그림으로 바꾸기

지금 들어 있는 캐릭터 그림은 **임시 그림**입니다. 직접 그린 것으로 바꾸면 됩니다.

### 그림 규칙

| 항목 | 값 |
| --- | --- |
| 크기 | **1000 × 1000 픽셀 정사각형** |
| 배경 | **투명** |
| 형식 | PNG 또는 SVG |

캐릭터는 **몸통 / 머리장식 / 눈 / 입** 네 장을 겹쳐서 만듭니다.
그래서 네 장 모두 **같은 1000×1000 정사각형** 위에 자기 자리에만 그려져 있어야 합니다.

> 💡 **가장 쉬운 방법**
> 일러스트레이터나 피그마에서 1000×1000 아트보드를 하나 만들고 캐릭터를 완성한 다음,
> 부위별로 하나씩만 켜서 각각 내보내기 하면 위치가 저절로 딱 맞습니다.

### 넣는 순서

1. 그림 파일을 `frontend/public/parts/` 안의 해당 폴더에 넣습니다.
   - `body/` 몸통 · `hair/` 머리장식 · `eyes/` 눈 · `mouth/` 입
2. `frontend/src/character/parts.js` 를 열어 목록에 파일 이름을 적습니다.

```js
export const PARTS = {
  body:  ['내몸통1.png', '내몸통2.png'],
  hair:  ['머리1.png', '머리2.png'],
  eyes:  ['눈1.png', '눈2.png'],
  mouth: ['입1.png', '입2.png'],
};
```

3. 저장하면 화면이 알아서 새로고침됩니다. 끝!

더 자세한 안내는 [`frontend/public/parts/README.md`](frontend/public/parts/README.md) 에 있습니다.

## 4. 글씨 바꾸기

| 바꾸고 싶은 것 | 고칠 파일 |
| --- | --- |
| 첫 화면 문구, 버튼 글씨 | `frontend/src/pages/NamePage.jsx` |

## 5. 사진은 어디에 저장되나요

```
backend/data/
├── uploads/       ← 사진 이미지 파일들 (.jpg)
└── photos.json    ← 누가 언제 찍었는지 적힌 목록
```

**이 폴더를 통째로 복사해두면 그게 곧 백업입니다.**
전시가 끝나면 이 폴더만 챙기면 모든 기록이 남습니다.

> 방문자 얼굴이 담긴 개인정보라서, 이 폴더는 깃허브에 올라가지 않도록 막아두었습니다.

### 실수로 찍힌 사진 지우기

갤러리에서 지우고 싶은 사진을 눌러 주소를 확인한 뒤 (`/p/여기가사진번호`),
터미널에서:

```bash
curl -X DELETE "http://localhost:4000/api/photos/사진번호?key=moimo-admin"
```

비밀번호(`moimo-admin`)는 `backend/server.js` 의 `ADMIN_KEY` 에서 바꿀 수 있습니다.

## 6. ⚠️ 전시 당일 준비 (꼭 읽어주세요)

전시 당일에 딱 두 가지가 문제가 될 수 있습니다. **미리 알고 계셔야 합니다.**

### 문제 ① 웹캠은 아무 주소에서나 켜지지 않습니다

브라우저 보안 규칙 때문에 카메라는 **`localhost` 또는 `https://` 주소**에서만 켜집니다.
`http://192.168.0.x` 같은 주소로 열면 카메라가 안 켜져요.

→ 전시장 컴퓨터에서는 **반드시 `localhost` 주소**로 여세요. 그러면 문제없습니다.

### 문제 ② `localhost` 주소는 방문자 폰에서 열리지 않습니다

QR코드에는 지금 보고 있는 주소가 담깁니다.
그런데 `localhost` 는 "이 컴퓨터"라는 뜻이라, 방문자가 폰으로 찍으면 아무것도 안 나옵니다.

**해결 방법 — 인터넷 주소를 하나 만들어서 그 주소로 전시장 화면을 띄우기**

`https://` 로 시작하는 진짜 주소가 생기면, 카메라도 켜지고 QR도 폰에서 열립니다. 한 번에 해결돼요.

방법은 두 가지가 있습니다.

| 방법 | 장점 | 단점 |
| --- | --- | --- |
| **A. 내 컴퓨터에서 서버를 켜고 터널로 주소만 빌리기**<br>(Cloudflare Tunnel 등) | 사진이 **내 컴퓨터에 안전하게** 쌓임 | 전시 중 컴퓨터를 계속 켜둬야 함 |
| **B. 인터넷 서버에 올리기**<br>(Render 등) | 컴퓨터를 꺼도 갤러리가 살아있음 | 사진이 지워지지 않게 하려면 저장공간 설정 필요 (보통 유료) |

> 졸업전시라면 **A 방법을 추천**합니다. 사진 원본이 내 손에 남는 게 안전하니까요.
> 어느 쪽이든 설정은 어렵지 않으니, 필요할 때 말씀해 주시면 같이 해드릴게요.

### 전시 당일 체크리스트

- [ ] 웹캠이 잘 연결되어 있는지 확인
- [ ] 브라우저를 **전체화면(F11)** 으로 띄우기
- [ ] 첫 화면(`/`)을 띄워두고 시작
- [ ] 카메라 권한 팝업이 뜨면 **"허용"** 을 눌러두기 (한 번만 하면 됨)
- [ ] 컴퓨터 절전·화면보호기 꺼두기
- [ ] 시험 삼아 한 번 찍어보고, `backend/data/uploads` 에 사진이 쌓이는지 확인
- [ ] 하루 끝나면 `backend/data` 폴더 백업

## 7. 문제가 생겼을 때

<details>
<summary><b>카메라가 안 켜져요</b></summary>

- 주소가 `localhost` 또는 `https://` 로 시작하는지 확인하세요. (위 6번 참고)
- 브라우저 주소창 왼쪽의 카메라 아이콘을 눌러 "허용"으로 바꿔주세요.
- 줌, 팀즈처럼 카메라를 쓰는 다른 프로그램이 켜져 있으면 끄세요.
</details>

<details>
<summary><b>사이트가 무한 로딩만 돌아요 / 서버 켜는 데 1분씩 걸려요</b></summary>

**먼저 기다려 보세요.** 터미널에 이 줄이 뜨기 전에는 사이트가 안 열립니다.

```
➜  Local:   http://localhost:5173/
```

이 줄이 나오는 데 1분 넘게 걸린다면, 프로젝트가 **데스크탑 폴더** 안에 있어서입니다.
맥의 "데스크탑 및 문서 폴더" iCloud 동기화가 켜져 있으면 파일 하나 읽을 때마다
iCloud 를 거치는데, 우리 프로젝트는 파일이 몇만 개(`node_modules`)라 아주 느려집니다.

동기화가 안 되는 곳으로 옮기면 몇 초로 줄어듭니다. 한 번만 실행하세요.

```bash
bash ~/Desktop/moimo/scripts/move-project.sh
```

폴더가 `~/moimo` 로 통째로 옮겨집니다. 안에 든 것은 하나도 안 바뀝니다.
끝나면 VS 코드에서 **파일 → 폴더 열기** 로 새 자리(`moimo`)를 다시 열어주세요.

그 뒤로는 폴더 주소가 `~/moimo` 입니다.
</details>

<details>
<summary><b>고쳤는데 화면에 옛날 것이 그대로 나와요</b></summary>

예전에 띄워놓고 안 끈 서버가 남아있는 겁니다. 다 끄고 다시 켜세요.

```bash
npm run stop
npm run dev
```
</details>

<details>
<summary><b>"갤러리를 불러오지 못했어요" 라고 나와요</b></summary>

사진 창고(서버)가 꺼져 있는 겁니다.
터미널에서 `npm run dev` 가 돌아가고 있는지 확인하세요.
</details>

<details>
<summary><b>글씨체가 이상하게 나와요</b></summary>

글씨체를 인터넷에서 받아오기 때문에, 인터넷이 끊기면 기본 글씨로 보입니다.
전시장 인터넷 연결을 확인하세요.
</details>

<details>
<summary><b>QR코드를 찍으면 아무것도 안 나와요</b></summary>

위 6번의 "문제 ②" 를 읽어주세요. 인터넷 주소가 필요합니다.
</details>

<details>
<summary><b>다 망가진 것 같아요. 처음부터 다시 하고 싶어요</b></summary>

```bash
rm -rf node_modules backend/node_modules frontend/node_modules
npm install
```

`backend/data` 폴더는 건드리지 않으니 사진은 그대로 남아있습니다.
</details>

## 8. 폴더가 무슨 역할인지

```
moimo/
├── frontend/                 ← 사람들이 보는 화면
│   ├── public/parts/         ← ★ 캐릭터 그림 파일들 (여기를 바꾸면 됩니다)
│   └── src/
│       ├── pages/            ← 화면 하나하나
│       ├── character/        ← 캐릭터를 만들고 그리는 로직
│       │   ├── parts.js      ← ★ 그림 목록 · 배경색 · 별명
│       │   ├── generate.js   ← 이름 → 캐릭터
│       │   └── draw.js       ← 웹캠 + 캐릭터를 사진 한 장으로 합치기
│       ├── components/       ← 여러 화면에서 같이 쓰는 조각
│       └── styles.css        ← ★ 디자인 (색, 글씨 크기 등)
│
├── backend/                  ← 사진을 보관하는 창고
│   ├── server.js             ← 사진 받기 / 갤러리 목록 주기
│   ├── storage.js            ← 파일로 저장하는 부분
│   └── data/                 ← ★ 찍힌 사진들이 쌓이는 곳 (백업 대상)
│
└── package.json              ← npm run dev 같은 명령어가 적힌 곳
```

★ 표시된 곳이 앞으로 자주 만지게 될 파일들입니다.
