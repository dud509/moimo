# 모이모 파츠 사양

이름을 입력하면 자모가 파츠로 매핑되어 모이모 한 마리가 조립된다.
같은 이름은 언제나 같은 모이모가 된다.

> ⚠️ 이 문서는 매핑표 이미지를 읽고 옮겨 적은 **초안**이다.
> `확인 필요` 표시된 곳은 확정 후 고칠 것.

---

## 1. 슬롯

| 이름 자리 | 자모 | 슬롯 | 파츠 수 | 폴더 |
|---|---|---|---|---|
| 성 | 초성 | 몸통 | 12 | `body/` |
| 성 | 중성 | 몸통 색깔 | 6 | *(헥사값, 파일 없음)* |
| 성 | 종성 | 몸통 무늬 | 5 + 없음 | `morph/` |
| 이름 1 | 초성 | 눈 | 11 | `eye/` |

## 2. 자모 → 파츠 매핑

번호는 매핑표 이미지의 읽는 순서(왼쪽→오른쪽, 윗줄→아랫줄)를 따른다.
파일 이름도 이 번호를 쓴다. 예: `body/01.svg`

### 몸통 — 성 초성 (12)

| # | 자모 |
|---|---|
| 01 | `김` (성 전체가 "김"일 때) |
| 02 | `이` |
| 03 | `박` |
| 04 | ㄱ (강·고·구·권·길 등 나머지 ㄱ) |
| 05 | ㄴ |
| 06 | ㅂ (배·백·변 등 나머지 ㅂ) |
| 07 | ㅅ |
| 08 | ㅇ (안·오·유·윤·임 등 나머지 ㅇ) |
| 09 | ㅈ |
| 10 | ㅊ |
| 11 | ㅎ |
| 12 | ㅁ ㄷ ㄹ ㅋ ㅌ ㅍ |

김·이·박은 **성씨 전체**를 먼저 보고, 아니면 초성으로 떨어진다.

### 몸통 색깔 — 성 중성 (6)

| # | 자모 | 색 | 헥사 |
|---|---|---|---|
| 01 | ㅣ + 받침 있음 | 파랑 | `#E1EEF4` |
| 02 | ㅏ | 노랑 | `#FFFAE3` |
| 03 | ㅓ | 분홍 | `#FFF0F4` |
| 04 | ㅗ 또는 ㅜ | 진갈색 | `#6B584B` |
| 05 | ㅣ + 받침 없음 | 민트 | `#E4F1EA` |
| 06 | 나머지 모음 | 연보라 | `#E8E3F3` |

색은 파일이 아니라 코드에서 몸통 채우기에 입힌다.

### 몸통 무늬(morph) — 성 종성 (5 + 없음)

| # | 자모 |
|---|---|
| 01 | ㄱ |
| 02 | ㄴ |
| 03 | ㅁ |
| 04 | ㅇ |
| 05 | ㄷ ㄹ ㅅ ㅈ ㅊ ㅋ ㅌ ㅍ ㅎ |
| — | 받침 없음 → 무늬 없음 (파일 없음) |

### 눈 — 이름 첫 글자 초성 (11)

`ㄱ ㄴ ㄷ ㄹ / ㅁ ㅂ ㅅ ㅇ / ㅈ ㅎ (ㅊㅋㅌㅍ)` 순서

### 입 — 이름 첫 글자 중성 (9)

`ㅏ ㅓ ㅕ / ㅗ ㅜ ㅡ ㅣ / (ㅐㅔㅒㅖ) (ㅑㅛㅠㅘㅝㅢㅟㅚㅙㅞ)` 순서

### 볼 장식 — 이름 첫 글자 종성 (6)

`ㄱ ㄴ / ㅇ ㅁ / 받침없음 (ㄷㄹㅅㅈㅊㅋㅌㅍㅎ)` 순서

> 몸통 무늬와 달리 여기서는 **받침없음도 그림이 있다.** `확인 필요`

### 머리 장식 — 이름 둘째 글자 초성 (11)

`ㄱ ㄴ ㄷ ㄹ / ㅁ ㅂ ㅅ ㅇ / ㅈ ㅎ (ㅊㅋㅌㅍ)` 순서

> 이미지에서 ㅈ 줄에 그림이 두 개로 보인다. `확인 필요`

### 꼬리 — 이름 둘째 글자 중성 (9)

입과 같은 자모 그룹 순서

### 몸통 장식 — 이름 둘째 글자 종성 (6)

`ㄱ ㄴ ㅇ / ㅁ 받침없음 / (ㄷㄹㅅㅈㅊㅋㅌㅍㅎ)` 순서

## 3. 파일 넣는 법

```
public/parts/
  body/    01.svg ~ 12.svg
  morph/   01.svg ~ 05.svg              (공용 5장. 몸통별로 덮어쓰려면 b01-m01.svg)
  eye/     01.svg ~ 11.svg
  mouth/   01.svg ~ 09.svg
  cheek/   01.svg ~ 06.svg
  hair/    01.svg ~ 11.svg
  tail/    01.svg ~ 09.svg
  deco/    01.svg ~ 06.svg
```

- **파일명은 두 자리 숫자.** 한글 자모를 파일명에 쓰면 맥/윈도우 사이에서
  유니코드 정규화(NFC/NFD)가 달라져 안 읽히는 일이 생긴다.
- **SVG 권장.** 몸통은 색을 코드에서 6가지로 갈아입혀야 해서, SVG면 파일
  12개로 끝나고 PNG면 12 × 6 = 72장을 따로 뽑아야 한다.
- 파츠마다 **여백을 자르지 말고** 같은 캔버스 크기로 내보내면 위치 잡기가
  훨씬 쉽다. (예: 전부 512 × 512)

## 3-0. 색을 고치는 곳

전부 **`src/moimo/parts.ts` 맨 위**에 모여 있다. 이 파일만 고치면 앵커 편집기와
사이트 양쪽에 함께 반영된다.

```ts
export const LINE_COLOR = '#38312A'        // 기본 선 색

export const BODY_COLORS = [
  { jamo: 'ㅣ받침', name: '파랑', hex: '#E1EEF4' },
  ...
  { jamo: 'ㅗㅜ', name: '진갈색', hex: '#6B584B', line: '#A08C79' },
]
```

- **선 색 전체를 바꾸려면** → `LINE_COLOR`
- **몸통 색을 바꾸려면** → 그 줄의 `hex`
- **특정 몸통 색일 때만 선을 다르게** → 그 줄에 `line: '#...'` 을 붙인다.
  안 붙이면 `LINE_COLOR` 를 쓴다.

원본 SVG 안의 값(`#888989`, `#FFFFFF`)은 그 아래 `SOURCE_LINE`, `SOURCE_FILL` 에
따로 있다. 에셋을 다시 뽑으면서 색을 바꾸지 않는 한 건드릴 일이 없다.

## 3-0-1. 몸통 안에서 색이 따로 노는 부분

배·얼굴판처럼 몸통 색과 다르게 가야 하는 부분은, 일러스트레이터에서
**그 부분만 마젠타 `#FF00FF` 로 칠해서** 내보낸다. 모이모 팔레트에 없는 색이라
다른 흰 영역과 헷갈리지 않는다.

화면에서는 몸통 색에 맞는 `accent` 로 바뀐다.

| 몸통 색 | 표시한 부분 |
|---|---|
| 파랑 · 노랑 · 분홍 | `#FFFFFF` 흰색 |
| 진갈색 | `#FFF4F3` 분홍 |

`BODY_COLORS` 각 줄의 `accent` 로 정한다. 몸통뿐 아니라 어느 파츠에서든
마젠타를 쓰면 같은 규칙이 적용된다.

## 3-1. 파츠 색

기본은 흰 채우기(`#FFFFFF`)를 그대로 둔다. 몸통 색을 따라가야 하는 파츠는
`parts.ts` 의 `TINTED` 에 적는다.

```ts
export const TINTED = {
  tail: 'all',   // 슬롯 전체
  eye: [11],     // 그 번호만
}
```

`'all'` 이면 그 슬롯의 파츠 전부, 배열이면 적은 번호만 몸통 색으로 채워진다.
**흰 영역이 없는 파츠는 여기 적어도 아무 변화가 없다** — 갈아입힐 흰색이 없기 때문.

볼장식과 입 07 에 들어 있는 분홍·크림(`#f6b3b1`, `#fce6e9`, `#ffe6ab` 등)은
갈아입히지 않고 그린 대로 나온다.

## 6. 앵커 편집기

```
npm install

```

(`npm run dev` 는 마을 화면을 연다.)

> 5273도 차 있으면 조용히 다른 포트로 옮겨가지 않고 에러를 낸다.

- 왼쪽에서 몸통 12종 중 하나를 고른다
- 오른쪽에서 슬롯(눈·입·볼·머리·꼬리·몸통장식)을 고른다
- 무대에서 **드래그**로 이동, **휠**로 크기, **←↑↓→** 1px(Shift 10px), **`[` `]`** 회전
- 슬롯의 `‹ ›` 로 파츠 번호를 넘겨가며 다른 변형에서도 자리가 맞는지 확인
- 위 색 버튼으로 몸통 색 6가지를 바꿔가며 확인 (진갈색일 땐 선이 밝은 갈색으로 바뀐다)
- **다른 몸통에서 복사** 로 비슷한 몸통의 앵커를 통째로 가져와 미세조정
- **저장하기** 를 누르면 `src/data/anchors.json` 에 바로 쓰인다

파일이 아직 없는 파츠는 점선 상자로 표시되니, 에셋을 넣는 대로 바로 나타난다.

### 무늬(morph) 파일 이름

**한 장을 그리면 열두 몸통이 같이 쓴다.** 무늬를 그릴 때 몸통 실루엣을
신경 쓰지 않아도 된다. 넉넉하게, 실루엣 밖으로 넘치도록 그려 두면
그리는 단계에서 그 몸통의 실루엣으로 잘라낸다. 고양이 귀는 뾰족하게,
토끼 귀는 늘어지게, 같은 그림이 몸통마다 제 모양을 얻는다.

```
morph/01.svg        무늬 01 — 열두 몸통 모두
morph/05.svg        무늬 05 — 열두 몸통 모두
```

어떤 몸통에서만 다르게 하고 싶으면 그 몸통 이름으로 한 장 더 두면 된다.
있으면 공용보다 이쪽이 이긴다.

```
morph/b03-m01.svg   몸통 03 에서의 무늬 01
```

받침이 없으면 무늬를 안 그리므로 그 조합의 파일은 없다.

**무늬는 몸통의 면과 선 사이에 깔린다.** 몸통을 통째로 덮지 않으므로
귀나 다리를 가르는 안쪽 선이 무늬 위로 그대로 보인다.

**무늬 색은 마젠타(`#FF00FF`)로 칠해 두면 강조색이 된다.** 몸통 색이
파랑·노랑·분홍·연보라면 흰색, 진갈색·흰색이면 분홍으로 바뀐다.

### 부위를 색으로 표시해 칠하기

귀처럼 몸통마다 자리가 다른 곳은 무늬 한 장으로 덮을 수 없다. 그럴 때는
그림 대신 **그 자리를 눈에 띄는 색으로 칠해 표시해 둔다.** 평소에는 몸통
색으로 덮어 없는 것처럼 두므로 화면에 형광색이 나오는 일은 없다.

**몸통 파일** `body/NN.svg` — 몸통마다 한 번만 해 두면 모든 무늬가 같이 쓴다.

| 표시 | 색 | 일러가 적는 이름 |
|---|---|---|
| 귀 면적 | `#00FF00` | `lime` |
| 귀 안쪽 핑크 | `#FF00FF` | `magenta` |

- 귀는 도형을 한 겹 덧대 표시한다. **좌우를 한 덩어리로 묶어도 된다.**
- 앞뒤 순서는 상관없다. 그릴 때 알아서 위로 올린다.

**무늬 파일** `morph/*.svg` — 그 무늬에서만 칠할 자리.

- **`#00FFFF`** (`aqua`) 로 칠한 도형이 무늬 색이 된다.
- **가장자리 마감은 그릴 때 한다.** 무늬 파일에 선이나 그라데이션을 넣지
  않아도 된다. 가장자리를 흐려 에어브러시처럼 번지게 한다.
  덩어리 가운데는 꽉 찬 색으로 남고 가장자리에서만 풀린다. `MORPH_EDGE` 가
  어떻게 마감할지, `MORPH_SPREAD` 가 풀리기 전에 모양을 얼마나 키울지,
  `MORPH_BLUR` 이 번지는 정도다. 어떤
  색만 다르게 하고 싶으면 그 줄에 `edge: 'line'` 을 붙인다.
- **표시해 둔 부위(귀)도 같은 방식으로 번진다.** 무늬 파일과 몸통 파일의
  표시가 같은 마감을 쓴다.
- **번지기는 귀와 얼굴에서만 한다.** 몸통과 팔다리에서 번지면 옷에 얼룩이
  진 것처럼 보인다. `HEAD_BOTTOM` 아래는 또렷하게 그리고, 그쪽 마감은
  `MORPH_BODY_EDGE` 가 정한다.
- 몸통 실루엣 밖으로 넘쳐도 된다. 그리는 단계에서 잘린다.

무늬가 몸통의 바깥까지 덮는 무늬는 `MORPH_TAIL` 에 적는다. 꼬리는 몸통에
이어 붙은 것이라, 몸통 바깥이 무늬 색이 되면 꼬리만 몸통 색으로 남아
동떨어져 보인다. 지금은 무늬 1·2 가 여기에 해당한다.

그리고 **귀 안쪽 분홍(`#FF00FF`)은 귀 면적 위로 올라간다.** 귀를 칠하는
무늬에서도 안쪽 분홍이 묻히지 않는다.

**무늬가 없으면 이름이 정한 색이 몸 전체를 칠한다. 무늬가 있으면 바탕은
희게 두고 그 색이 무늬로 간다.** 한 마리가 두 색을 갖지 않게 하려는 것이다.
몸 전체를 칠할 때와 무늬로 갈 때가 **같은 색**이라야 「파랑」이 두 가지
파랑으로 갈라지지 않는다. 그 줄의 `hex` 하나면 된다.

무늬마다 몸통 파일의 어느 표시를 쓸지는 `src/moimo/parts.ts` 의
`REGION_MORPH` 다. `쪽` 을 적으면 캔버스 한가운데를 기준으로 그 반만 칠한다.
**여기에 적히지 않아도 그 무늬의 무늬 파일은 늘 함께 그려진다.**

```ts
export const REGION_MORPH: Record<number, RegionSpec[]> = {
  1: [{ 부위: '귀' }],            // 귀 양쪽 + 무늬 파일
  2: [],                          // 무늬 파일만 — 귀는 건드리지 않는다
  3: [],                          // 무늬 파일만
  4: [{ 부위: '귀', 쪽: '왼' }],  // 왼쪽 귀 + 무늬 파일
  5: [],                          // 무늬 파일만
}
```

**표시가 없는 몸통은 예전처럼 무늬 파일을 쓴다.** 열두 몸통을 한꺼번에
고칠 필요 없이 한 몸통씩 옮겨 가면 된다.

> **지금 들어 있는 60장은 자리를 지키는 임시 무늬다.**
> 몸통 실루엣 안쪽에 점·줄·배·얼룩·물방울을 넣어 자동으로 뽑은 것이라,
> 그린 파일로 덮어쓰면 그대로 바뀐다. 공용 한 장(`morph/01.svg`)을 쓰려면
> 그 무늬의 몸통별 파일 열두 장을 지워야 공용 쪽으로 떨어진다.

## 7. 앵커가 네 겹인 이유

파츠가 붙는 자리는 몸통마다도, 파츠마다도 다르다. 그렇다고 몸통 12 ×
머리장식 11 = 132개를 손으로 잡을 수는 없다. 그래서 넓은 데서 좁은 데로 겹쳐 쌓는다.

| 층 | 담는 것 | 편집기 버튼 |
|---|---|---|
| `slots` | 12종이 함께 쓰는 기준 자리 | **기준 (모든 몸통)** |
| `bodies` | 그 몸통만 기준에서 얼마나 벗어나는지 | **이 몸통만** |
| `parts` | 그 번호의 파츠만 | **이 파츠** |
| `overrides` | 그래도 어색한 한 조합만 | **이 조합만** |

아래 세 층은 기준에 **더해지는 보정**이라, 비어 있으면 기준 그대로다.
기준을 나중에 옮겨도 몸통별로 잡아둔 차이는 그대로 따라온다.

**순서대로 잡는 게 빠르다.**

1. **기준** 으로 눈·입·볼·꼬리·몸통장식의 자리를 한 번씩 잡는다 (몸통 아무거나 보면서)
2. 몸통을 12종 넘겨보며 어긋나는 것만 **이 몸통만** 으로 민다
3. 머리장식은 기준을 잡은 뒤 **이 파츠** 로 02~11 을 01 대비 보정한다
4. 그래도 남는 몇 개만 **이 조합만**

### 좌우로 벌리기

양쪽 귀에 거는 날개처럼 **몸통 폭에 맞춰야 하는 파츠**는 가로로 늘리면 찌부된다.
`벌림` 값을 쓰면 파츠를 한가운데서 갈라 양쪽으로 밀어내므로 모양이 그대로다.

좌우 대칭인 파츠(날개·귀·쌍리본)에만 뜻이 있다. 한쪽에만 있는 장식에 쓰면
가운데가 갈라져 어긋난다.

### 모아보기

한 조합만 보고 있으면 12종에 다 맞는지 알 수 없다. 위쪽 버튼으로 늘어놓고 본다.

- **몸통 12종** — 지금 파츠를 12종 몸통에 얹어 한 번에. 어느 몸통에서 어긋나는지 바로 보인다
- **○○ 전종** — 지금 몸통에 그 슬롯 파츠를 전부. 리본은 맞는데 왕관만 뜨는 식의 문제를 잡는다

어긋난 칸을 누르면 그 몸통·파츠로 옮겨간다. 고치고 다시 모아보기로 확인하는 식으로 돈다.
