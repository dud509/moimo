# 모이모 파츠 사양

이름을 입력하면 자모가 파츠로 매핑되어 모이모 한 마리가 조립된다.
같은 이름은 언제나 같은 모이모가 된다.

> ⚠️ 이 문서는 매핑표 이미지를 읽고 옮겨 적은 **초안**이다.
> `확인 필요` 표시된 곳은 확정 후 고칠 것.

## 2. 자모 → 파츠 매핑

번호는 매핑표 이미지의 읽는 순서(왼쪽→오른쪽, 윗줄→아랫줄)를 따른다.
파일 이름도 이 번호를 쓴다. 예: `body/01.svg`

| # | 자모 |
|---|---|
| 01 | `김` (성 전체가 "김"일 때) |
| 02 | `이` |
| 03 | `박` |
| 04 | ㄱ (강·고·구·권·길 등 나머지 ㄱ) |
| 05 | ㄴ |
| 06 | ㅂ (배·백·변 등 나머지 ㅂ) |
| 07 | ㅅ |
| 08 | ㅇ (안·오·유·윤·임 등 나머지 ㅇ) |

| 10 | ㅊ |
| 11 | ㅎ |
| 12 | ㅁ ㄷ ㄹ ㅋ ㅌ ㅍ |

김·이·박은 **성씨 전체**를 먼저 보고, 아니면 초성으로 떨어진다.

### 몸통 색깔 — 성 중성 (6)

| # | 자모 | 색 | 헥사 |
|---|---|---|---|
| 01 | ㅣ | 파랑 | `#E1EEF4` |
| 02 | ㅏ | 노랑 | `#FFFAE3` |
| 03 | ㅓ | 분홍 | `#FFD8E2` |

| 06 | ㅡ ㅐ ㅔ ㅑ ㅛ ㅠ | 갈색 | `#5F5040` |

### 몸통 무늬(morph) — 성 종성 (5 + 없음)

| # | 자모 |
|---|---|
| 01 | ㄱ |
| 02 | ㄴ |

| 04 | ㅇ |

### 눈 — 이름 첫 글자 초성 (11)

`ㄱ ㄴ ㄷ ㄹ / ㅁ ㅂ ㅅ ㅇ / ㅈ ㅎ (ㅊㅋㅌㅍ)` 순서

### 입 — 이름 첫 글자 중성 (9)

`ㅏ ㅓ ㅕ / ㅗ ㅜ ㅡ ㅣ / (ㅐㅔㅒㅖ) (ㅑㅛㅠㅘㅝㅢㅟㅚㅙㅞ)` 순서

### 볼 장식 — 이름 첫 글자 종성 (6)

`ㄱ ㄴ / ㅇ ㅁ / 받침없음 (ㄷㄹㅅㅈㅊㅋㅌㅍㅎ)` 순서

> 몸통 무늬와 달리 여기서는 **받침없음도 그림이 있다.** `확인 필요`

### 머리 장식 — 이름 둘째 글자 초성 (11)

`ㄱ ㄴ ㄷ ㄹ / ㅁ ㅂ ㅅ ㅇ / ㅈ ㅎ (ㅊㅋㅌㅍ)` 순서

> 이미지에서 ㅈ 줄에 그림이 두 개로 보인다. `확인 필요`

### 꼬리 — 이름 둘째 글자 중성 (9)

입과 같은 자모 그룹 순서

### 몸통 장식 — 이름 둘째 글자 종성 (6)

`ㄱ ㄴ ㅇ / ㅁ 받침없음 / (ㄷㄹㅅㅈㅊㅋㅌㅍㅎ)` 순서

## 3. 파일 넣는 법

```
public/parts/
  body/    01.svg ~ 12.svg
  morph/   b01-m01.svg ~ b12-m05.svg   (몸통 12 × 무늬 5 = 60장, 받침없음은 파일 없음)
  eye/     01.svg ~ 11.svg
  mouth/   01.svg ~ 09.svg
  cheek/   01.svg ~ 06.svg
  hair/    01.svg ~ 11.svg
  tail/    01.svg ~ 09.svg
  deco/    01.svg ~ 06.svg
```

- **파일명은 두 자리 숫자.** 한글 자모를 파일명에 쓰면 맥/윈도우 사이에서
  유니코드 정규화(NFC/NFD)가 달라져 안 읽히는 일이 생긴다.
- **SVG 권장.** 몸통은 색을 코드에서 6가지로 갈아입혀야 해서, SVG면 파일
  12개로 끝나고 PNG면 12 × 6 = 72장을 따로 뽑아야 한다.
- 파츠마다 **여백을 자르지 말고** 같은 캔버스 크기로 내보내면 위치 잡기가
  훨씬 쉽다. (예: 전부 512 × 512)

## 3-0. 색을 고치는 곳

전부 **`src/moimo/parts.ts` 맨 위**에 모여 있다. 이 파일만 고치면 앵커 편집기와
사이트 양쪽에 함께 반영된다.

```ts
export const LINE_COLOR = '#38312A'        // 기본 선 색

export const BODY_COLORS = [
  { jamo: 'ㅣ', name: '파랑', hex: '#E1EEF4' },
  ...
  { jamo: 'ㅗ', name: '검정', hex: '#231A17', line: '#665546' },
]
```

- **선 색 전체를 바꾸려면** → `LINE_COLOR`
- **몸통 색을 바꾸려면** → 그 줄의 `hex`
- **특정 몸통 색일 때만 선을 다르게** → 그 줄에 `line: '#...'` 을 붙인다.
  안 붙이면 `LINE_COLOR` 를 쓴다.

원본 SVG 안의 값(`#888989`, `#FFFFFF`)은 그 아래 `SOURCE_LINE`, `SOURCE_FILL` 에
따로 있다. 에셋을 다시 뽑으면서 색을 바꾸지 않는 한 건드릴 일이 없다.

## 3-0-1. 몸통 안에서 색이 따로 노는 부분

배·얼굴판처럼 몸통 색과 다르게 가야 하는 부분은, 일러스트레이터에서
**그 부분만 마젠타 `#FF00FF` 로 칠해서** 내보낸다. 모이모 팔레트에 없는 색이라
다른 흰 영역과 헷갈리지 않는다.

화면에서는 몸통 색에 맞는 `accent` 로 바뀐다.

| 몸통 색 | 표시한 부분 |
|---|---|
| 파랑 · 노랑 · 분홍 | `#FFFFFF` 흰색 |
| 검정 · 흰색 · 갈색 | `#FFF4F3` 분홍 |

`BODY_COLORS` 각 줄의 `accent` 로 정한다. 몸통뿐 아니라 어느 파츠에서든
마젠타를 쓰면 같은 규칙이 적용된다.

## 3-1. 파츠 색

기본은 흰 채우기(`#FFFFFF`)를 그대로 둔다. 몸통 색을 따라가야 하는 파츠는
`parts.ts` 의 `TINTED` 에 적는다.

```ts
export const TINTED = {
  tail: 'all',   // 슬롯 전체
  eye: [11],     // 그 번호만
}
```

`'all'` 이면 그 슬롯의 파츠 전부, 배열이면 적은 번호만 몸통 색으로 채워진다.
**흰 영역이 없는 파츠는 여기 적어도 아무 변화가 없다** — 갈아입힐 흰색이 없기 때문.

볼장식과 입 07 에 들어 있는 분홍·크림(`#f6b3b1`, `#fce6e9`, `#ffe6ab` 등)은
갈아입히지 않고 그린 대로 나온다.

## 6. 앵커 편집기

```
npm install
npm run dev
```
브라우저가 **http://localhost:5273/anchors.html** 로 알아서 열린다.

> 포트가 **5273**인 건 예전 프로젝트(5173)와 겹치지 않게 하려는 것이다.
> 5273도 차 있으면 조용히 다른 포트로 옮겨가지 않고 에러를 낸다.
> 월드 화면은 `npm run site`.

- 왼쪽에서 몸통 12종 중 하나를 고른다
- 오른쪽에서 슬롯(눈·입·볼·머리·꼬리·몸통장식)을 고른다
- 무대에서 **드래그**로 이동, **휠**로 크기, **←↑↓→** 1px(Shift 10px), **`[` `]`** 회전
- 슬롯의 `‹ ›` 로 파츠 번호를 넘겨가며 다른 변형에서도 자리가 맞는지 확인
- 위 색 버튼으로 몸통 색 6가지를 바꿔가며 확인 (검정·갈색일 땐 선이 흰색으로 바뀐다)
- **다른 몸통에서 복사** 로 비슷한 몸통의 앵커를 통째로 가져와 미세조정
- **저장하기** 를 누르면 `src/data/anchors.json` 에 바로 쓰인다

파일이 아직 없는 파츠는 점선 상자로 표시되니, 에셋을 넣는 대로 바로 나타난다.

### 무늬(morph) 파일 이름

무늬는 몸통 모양마다 따로 그리므로 **몸통 12 × 무늬 5 = 60장**이다.

```
morph/b01-m01.svg   몸통 01 의 무늬 01
morph/b12-m05.svg   몸통 12 의 무늬 05
```

받침이 없으면 무늬를 안 그리므로 그 조합의 파일은 없다.
공용으로 하나만 쓰고 싶은 무늬가 있으면 `morph/01.svg` 로 두면 몸통별 파일이
없을 때 그쪽으로 떨어진다.

## 7. 앵커가 네 겹인 이유

파츠가 붙는 자리는 몸통마다도, 파츠마다도 다르다. 그렇다고 몸통 12 ×
머리장식 11 = 132개를 손으로 잡을 수는 없다. 그래서 넓은 데서 좁은 데로 겹쳐 쌓는다.

| 층 | 담는 것 | 편집기 버튼 |
|---|---|---|
| `slots` | 12종이 함께 쓰는 기준 자리 | **기준 (모든 몸통)** |
| `bodies` | 그 몸통만 기준에서 얼마나 벗어나는지 | **이 몸통만** |
| `parts` | 그 번호의 파츠만 | **이 파츠** |
| `overrides` | 그래도 어색한 한 조합만 | **이 조합만** |

아래 세 층은 기준에 **더해지는 보정**이라, 비어 있으면 기준 그대로다.
기준을 나중에 옮겨도 몸통별로 잡아둔 차이는 그대로 따라온다.

**순서대로 잡는 게 빠르다.**

1. **기준** 으로 눈·입·볼·꼬리·몸통장식의 자리를 한 번씩 잡는다 (몸통 아무거나 보면서)
2. 몸통을 12종 넘겨보며 어긋나는 것만 **이 몸통만** 으로 민다
3. 머리장식은 기준을 잡은 뒤 **이 파츠** 로 02~11 을 01 대비 보정한다
4. 그래도 남는 몇 개만 **이 조합만**
