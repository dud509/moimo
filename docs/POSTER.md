# 포스터 뽑기

모이모를 한 장에 잔뜩 모아 인쇄용 파일로 내보낸다.
화면에 뜨는 모이모와 같은 `composeMoimo` 를 쓰므로, 웹에서 본 얼굴이 그대로 종이에 간다.

## 보면서 맞추기

```
npm run poster:dev      # /poster.html 이 열린다
```

주소 뒤에 값을 붙이면 바로 다시 그린다.

```
/poster.html?count=180&seed=3&rowFactor=0.55
```

| 값 | 기본 | 뜻 |
| --- | --- | --- |
| `seed` | 11 | 씨앗. 같은 값이면 언제나 같은 포스터 |
| `count` | 150 | 마리 수. **크기는 여기에 맞춰 저절로 정해진다** |
| `width` `height` | 420×594 | 종이 크기 (mm, A2 세로) |
| `bleed` | 6 | 재단선 바깥 여유 (mm) |
| `overlap` | 0.22 | 가로로 겹치는 정도 |
| `rowFactor` | 0.6 | 줄 간격. 작을수록 위아래로 빽빽 |
| `spread` | 0.3 | 크기 들쭉날쭉한 정도 |
| `tilt` | 7 | 기울이는 최대 각도 |
| `title` | 1 | `0` 이면 로고 자리를 비우지 않고 꽉 채운다 |
| `background` | `#FFFFFF` | 종이 색 |

## 파일로 내보내기

```
npm run poster
npm run poster -- --count=200 --seed=5 --dpi=350 --width=500 --height=700
```

`out/` 에 세 벌이 떨어진다.

- `poster.svg` — 벡터 원본. 인쇄소에 넘기기 가장 좋다
- `poster.pdf` — 종이 크기(mm)가 박힌 벡터 PDF
- `poster.png` — 300dpi 래스터. 확인용·굿즈용

## 아는 사람만 아는 것

- 파츠는 512 칸 한가운데에 여백을 크게 두고 그려져 있다. 캔버스째로 늘어놓으면
  모이모 사이가 허전해져서, 실측한 그림 네모(`artCx/artCy/artSize`)만 자리로 친다.
- 몸통 색은 원래 성(姓)이 정한다. 무작위로 두면 한 색으로 쏠려서,
  포스터에서는 여섯 색을 돌아가며 박는다.
- 같은 유전자가 두 번 나오지 않게 걸러낸다. 150마리면 150마리 다 다른 얼굴이다.
