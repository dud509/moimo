# 캐릭터 그림(파츠) 넣는 방법

지금 이 폴더에 들어 있는 그림들은 **임시 그림**입니다.
직접 그린 그림으로 바꾸면 바로 그 그림으로 캐릭터가 만들어집니다.

---

## 그림 그릴 때 지켜야 할 규칙

| 항목 | 값 |
| --- | --- |
| 크기 | **1000 × 1000 픽셀 정사각형** |
| 배경 | **투명** (흰색 아님!) |
| 파일 형식 | PNG 또는 SVG |

모든 파츠는 **같은 크기의 정사각형 위에 각자 자기 자리에만 그려져 있어야** 합니다.
1000×1000 캔버스 4장(몸통 / 머리장식 / 눈 / 입)을 그대로 겹치면 캐릭터 한 마리가 되는 구조입니다.

가장 쉬운 방법: **일러스트레이터나 피그마에서 1000×1000 아트보드를 하나 만들고,
그 위에 캐릭터를 완성한 다음, 부위별로 하나씩만 켜서 각각 내보내기** 하면 됩니다.
그러면 위치가 자동으로 딱 맞습니다.

### 임시 그림이 쓰고 있는 위치 (참고용)

| 부위 | 대략적인 위치 |
| --- | --- |
| 몸통 | 가운데 (500, 570) 근처, 위아래로 280 ~ 870 |
| 눈 | 왼쪽 눈 (405, 520) / 오른쪽 눈 (595, 520) |
| 입 | (500, 645) |
| 머리 장식 | (500, 250) 근처, 몸통 위쪽 |

꼭 이대로일 필요는 없어요. 본인 캐릭터에 맞게 정하고, 모든 파츠를 그 기준으로 통일하면 됩니다.

---

## 폴더 구조

```
parts/
├── body/    ← 몸통
├── hair/    ← 머리 장식
├── eyes/    ← 눈
└── mouth/   ← 입
```

겹치는 순서는 **몸통 → 머리 장식 → 눈 → 입** 입니다. (뒤에 오는 것이 위에 그려집니다)

---

## 바꾸는 순서

1. 그린 그림을 위 폴더 안에 넣습니다. (예: `body/내몸통1.png`)
2. `frontend/src/character/parts.js` 파일을 열어서 목록에 파일 이름을 적습니다.

```js
export const PARTS = {
  body: ['내몸통1.png', '내몸통2.png', '내몸통3.png'],
  hair: ['머리1.png', '머리2.png'],
  eyes: ['눈1.png', '눈2.png', '눈3.png'],
  mouth: ['입1.png', '입2.png'],
};
```

3. 저장하면 화면이 자동으로 새로고침됩니다. 끝!

> 파일 개수는 자유입니다. 부위마다 개수가 달라도 괜찮아요.
> 조합 가짓수 = 몸통 수 × 머리 수 × 눈 수 × 입 수 × 배경색 수 입니다.
> (지금은 5 × 6 × 6 × 5 × 8 = **7,200가지**)

---

## 배경색도 바꾸고 싶다면

같은 `parts.js` 파일 안의 `BACKGROUNDS` 목록을 고치면 됩니다.
`TITLES`(이름 앞에 붙는 별명)도 여기서 바꿀 수 있어요.
