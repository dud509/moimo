# ⚠️ 이 폴더의 그림은 전부 "임시 그림"입니다

여기 들어있는 SVG들은 **피그마 시안을 보고 대충 흉내 낸 가짜**입니다.
레이아웃과 위치를 잡아두려고 만든 것이라, 진짜 그림으로 바꿔야 합니다.

대화창에 올려주신 이미지는 **화면 전체를 찍은 스크린샷 한 장**이라,
그 안에 있는 다이어리·카메라·가방을 따로 떼어내 쓸 수가 없습니다.
(배경이 같이 붙어 있고, 투명 배경이 아니라서요.)

**피그마에서 요소별로 따로 내보내 주셔야** 진짜 그림이 들어갑니다.

---

## 피그마에서 내보내는 법

1. 왼쪽 레이어 목록에서 **요소 하나를 클릭** (예: 다이어리 그룹)
2. 오른쪽 패널 맨 아래 `Export` 섹션의 **+** 버튼
3. **`SVG`** 를 고릅니다 → `Export` 클릭
   - SVG 가 안 되면 `PNG` + `3x` 로 하고, 아래 표의 파일 이름에서 확장자만 `.png` 로 바꾸세요
4. 아래 표의 **정확한 파일 이름**으로 저장해서 이 폴더에 넣습니다

> **오브젝트(다이어리·카메라 등)를 내보낼 때는 배경을 빼고** 그 물건만 내보내세요.
> 배경은 `background.svg` 한 장이 따로 담당합니다.

> 주소로 불러올 때 깨집니다. `speechbubble.svg` 처럼 붙여서 저장하세요.

### 말풍선 안의 글자 위치가 안 맞으면

말풍선은 그림 위에 글자를 얹는 방식입니다. 글자가 꼬리 쪽으로 치우쳐 보이면
`frontend/src/styles.css` 의 `.speech-bubble` 에 있는 숫자 세 개만 고치세요.

```css
--bubble-w: clamp(120px, 11vw, 190px);  /* 말풍선 크기 */
--bubble-text-x: 50%;                   /* 글자 가로 위치 */
--bubble-text-y: 44%;                   /* 글자 세로 위치 */
```

## ⚠️ 배경(`background.svg`)은 이제 쓰지 않습니다

전시장 화면의 배경(하늘색 띠 + 크림 바탕 + 물방울)은 **그림이 아니라 CSS 로 그립니다.**
그래서 이 파일을 새로 내보내도 화면은 바뀌지 않습니다.

**왜 바꿨나요?**
화면 비율이 시안(16:9)과 다를 때, 그림이면 남는 자리를 채울 방법이 없습니다.
CSS 로 그리면 하늘색은 하늘색으로, 물방울은 물방울로 끝없이 이어집니다.

**배경을 고치려면** `frontend/src/styles.css` 맨 위 `:root` 안의 숫자를 고치세요.
값은 모두 `background.svg` 를 실제로 재서 넣은 것입니다.

```css
--sky: #c7dbe2;      /* 위아래 하늘색 띠 */
--cream: #fff9e9;    /* 가운데 크림 바탕 */
--dot: #c7dbe2;      /* 물방울 색 */
--dot-gap: 86.5px;   /* 물방울 사이 간격 */
--dot-size: 17px;    /* 물방울 지름 */
--header-h: 244px;   /* 위 띠 높이 (시안 기준) */
--footer-h: 64px;    /* 아래 띠 높이 (시안 기준) */
```

> 물방울 무늬 자체가 완전히 다른 모양으로 바뀐다면(별, 하트 등) 그때는
> 말씀해 주세요. 그림 파일로 다시 돌리는 쪽이 맞습니다.

## 메인 화면에서 물건 위치 옮기기

`frontend/src/pages/MainPage.jsx` 파일 위쪽 `OBJECTS` 목록에서
`left`, `top`, `width` 숫자(%)만 고치면 자리가 바뀝니다.

```js
{
  key: 'diary',
  style: { left: '17%', top: '28%', width: '23%' },  // ← 이 숫자
  tilt: -6,                                          // ← 기울기(도)
}
```
