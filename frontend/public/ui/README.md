# ⚠️ 이 폴더의 그림은 전부 "임시 그림"입니다

여기 들어있는 SVG들은 **피그마 시안을 보고 대충 흉내 낸 가짜**입니다.
레이아웃과 위치를 잡아두려고 만든 것이라, 진짜 그림으로 바꿔야 합니다.

대화창에 올려주신 이미지는 **화면 전체를 찍은 스크린샷 한 장**이라,
그 안에 있는 다이어리·카메라·가방을 따로 떼어내 쓸 수가 없습니다.
(배경이 같이 붙어 있고, 투명 배경이 아니라서요.)

**피그마에서 요소별로 따로 내보내 주셔야** 진짜 그림이 들어갑니다.

---

## 피그마에서 내보내는 법

1. 왼쪽 레이어 목록에서 **요소 하나를 클릭** (예: 다이어리 그룹)
2. 오른쪽 패널 맨 아래 `Export` 섹션의 **+** 버튼
3. **`SVG`** 를 고릅니다 → `Export` 클릭
   - SVG 가 안 되면 `PNG` + `3x` 로 하고, 아래 표의 파일 이름에서 확장자만 `.png` 로 바꾸세요
4. 아래 표의 **정확한 파일 이름**으로 저장해서 이 폴더에 넣습니다

> 배경(크림색·물방울무늬·하늘색 띠)은 **내보내지 마세요.**
> 그건 코드로 그리고 있어서, 그림에 같이 들어가면 겹쳐 보입니다.

---

## 필요한 파일 목록

| 파일 이름 | 무엇 | 어느 화면 |
| --- | --- | --- |
| `logo.svg` | moimo 로고 (구름 + 글자) | 모든 화면 위쪽 |
| `diary.svg` | 핑크 다이어리 | 메인 |
| `camera.svg` | 파란 카메라 | 메인 · 결과 오른쪽 메뉴 |
| `polaroid.svg` | 폴라로이드 사진 뭉치 | 메인 · 결과 오른쪽 메뉴 |
| `bag.svg` | 노란 쇼핑백 | 메인 · 결과 오른쪽 메뉴 |
| `mascot.svg` | 말풍선 옆 작은 캐릭터 | 메인 오른쪽 아래 |
| `unknown.svg` | 회색 "아직 정해지지 않은" 모이모 | 이름 입력 |
| `home.svg` | 집 모양 아이콘 | 태블릿 왼쪽 홈 버튼 |

**파일 이름만 똑같이 맞춰서 덮어쓰면 끝입니다.** 코드는 안 고쳐도 돼요.

## 메인 화면에서 물건 위치 옮기기

`frontend/src/pages/MainPage.jsx` 파일 위쪽 `OBJECTS` 목록에서
`left`, `top`, `width` 숫자(%)만 고치면 자리가 바뀝니다.

```js
{
  key: 'diary',
  style: { left: '17%', top: '28%', width: '23%' },  // ← 이 숫자
  tilt: -6,                                          // ← 기울기(도)
}
```
