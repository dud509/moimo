# 오브제 그림

파일을 놓으면 그린 그림 대신 이 그림을 쓴다. **한 개씩 옮겨 갈 수 있다.**
없는 것은 예전 그림 그대로 나온다.

| 파일 | 오브제 | 화면에 놓이는 크기 |
|---|---|---|
| `jar.png` | 별사탕 유리병 | 300 |
| `camera.png` | 카메라 | 250 |
| `album.png` | 앨범 | 250 |
| `glass.png` | 돋보기 | 230 |
| `music.png` | 플레이어 | 220 |

- **정사각형**으로, 배경을 **투명**하게 내보낸다
- 그림은 아래쪽에 맞춰 놓인다. 바닥에 닿는 물건이라 그렇다
- 크기는 `src/world/model.ts` 의 `ITEMS` 에서 `w` 를 고치면 된다

## 소품 — `deco1.png` ~ `deco5.png`

캐릭터 사이사이에 깔리는 작은 그림들. 오브제와 달리 **클릭할 수 없고**
마을 곳곳에 흩뿌려진다. 없는 파일은 조용히 빠지므로 한 개씩 늘려도 된다.

- 배경을 **투명**하게, 여백 없이 딱 맞게 잘라서 내보낸다
- 정사각형이 아니어도 된다. 가로 폭만 맞추고 높이는 비율대로 따라간다

두 층으로 나뉘어 깔린다 — 같은 그림이라도 뽑히는 층에 따라 달리 보인다.

| 층 | 크기 | 진하기 | 하는 일 |
|---|---|---|---|
| 바닥층 (약 1/3) | 150~260 | 0.3 | 빈 땅을 옅게 메운다 |
| 사이층 (약 2/3) | 46~104 | 0.9 | 모이모 사이에 또렷하게 끼어든다 |

- 모이모 **아래**에 깔린다. 소품이 캐릭터를 가리는 일은 없다
- 오브제 다섯 개는 끝까지 비켜 간다
- 소품끼리도 뭉치지 않게 서로 거리를 둔다
- 마을 한가운데는 모이모가 빽빽해 어차피 안 보이므로 성기게 깔린다

수·크기·진하기는 `src/world/model.ts` 의 `PROP_COUNT`, `PROP_BACK`,
`PROP_FRONT`, `PROP_BACK_SHARE` 에서, 개수는 `src/world/World.tsx` 의
`DECO_COUNT` 에서 고친다.
