# 오브제 그림

마을에 놓이는 그림들. 모두 SVG 이고, 여백은 코드가 알아서 잘라낸다 —
아트보드 크기와 상관없이 적어 둔 폭으로 놓인다.

| 파일 | 무엇 | 누를 수 있나 |
|---|---|---|
| `jar02.svg` | 별사탕 유리병 (모이모 만들기) | ○ |
| `camera.svg` | 카메라 (같이 사진찍기) | ○ |
| `album.svg` | 앨범 (기록과 방명록) | ○ |
| `glass.svg` | 돋보기 (이름 찾아보기) | ○ |
| `gift.svg`, `book.svg`, `inbox01.svg`, `inbox02.svg`, `box01.svg` | 꾸밈 | × |
| `guide01.svg`, `guide02.svg` | 유리병 곁에 서 있는 안내 캐릭터 | × |
| `starcandy01~04.svg` | 마을에 흩뿌리는 별사탕 | × |

자리와 크기는 `src/world/model.ts` 에서 고친다.

- `ITEMS` — 누를 수 있는 오브제
- `DECOR` — 꾸밈 오브제
- `GUIDES` — 안내 캐릭터
- `PROP_KINDS`, `PROP_COUNT` — 별사탕 종류·크기·개수

`x`, `y` 는 그림의 **한가운데**, `w` 는 화면에 보이는 폭이다. `ratio`(세로/가로)는
모이모가 비켜 설 자리를 미리 재는 데 쓰므로, 그림 비율을 크게 바꾸면 함께 고친다.
자리는 시안(1466×978, 처음 배율 0.75)에서 옮겨 왔다 — 시안의 1px 이 마을의
1.333px 이고, 시안 한가운데가 마을 한가운데(1800, 1200)다.

그림자는 코드가 그린다. 그림 파일에 그림자를 넣지 않는다.
