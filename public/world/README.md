# 배경 그림

`background.png` 를 이 폴더에 놓으면 월드 배경으로 깔린다.

- 이름은 `background.jpg` 또는 `background.png`. 지금은 `.jpg` 를 쓴다
- 크기: **3600 × 2400** (월드와 같은 비율이면 된다. 더 커도 줄여서 쓴다)
- 없으면 크림색 바탕과 옅은 얼룩만 남는다 — 오류가 나지는 않는다
- 배경은 모이모와 함께 움직이고 확대·축소된다

# 로고

`logo.png` 를 놓으면 왼쪽 위 「모이모 / MOIMO WORLD」 글자 대신 쓰인다.

- 높이 **52px** 로 놓인다. 가로는 비율대로 늘어난다 (넉넉히 2~3배로 그려 두면 선명하다)
- 배경 **투명**
- 배경 그림에 로고를 그려 넣었다면 `src/App.tsx` 의 `HIDE_BRAND` 를 `true` 로 두어 글자를 아예 지울 수 있다
