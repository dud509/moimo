# 소품

캐릭터 사이사이에 깔리는 작은 그림들. **이 폴더에 png 를 넣기만 하면 된다** —
파일 이름도, 개수도 상관없다. 넣는 대로 마을 전체에 흩뿌려지고, 하나도
없으면 아무것도 안 나온다.

```
src/world/props/star.png
src/world/props/clover.png
src/world/props/ribbon.png
...
```

- 배경을 **투명**하게, 여백을 거의 남기지 않고 딱 맞게 잘라서 내보낸다
- 한 파일에 하나씩. 여러 개를 한 장에 모아 두면 따로 흩뿌릴 수 없다
- 정사각형이 아니어도 된다. 가로 폭만 맞추고 높이는 비율대로 따라간다
- `png` `webp` `svg` 를 받는다

## `_샘플-…svg` 는 지우면 된다

지금 들어 있는 `_샘플-` 다섯 개는 자리만 잡아 둔 임시 그림이다.
진짜 소품이 생기면 **지우면 된다** — 남은 그림만 쓰인다.

## 어떻게 깔리나

소품은 두 층으로 나뉜다 — 같은 그림이라도 뽑히는 층에 따라 달리 보인다.

| 층 | 크기 | 진하기 | 하는 일 |
|---|---|---|---|
| 바닥층 (약 1/3) | 150~300 | 0.3 | 빈 땅을 옅게 메운다 |
| 사이층 (약 2/3) | 46~104 | 0.9 | 모이모 사이에 또렷하게 끼어든다 |

- 모이모 **아래**에 깔린다. 소품이 캐릭터를 가리는 일은 없다
- 오브제(유리병·카메라·앨범·돋보기·플레이어)는 끝까지 비켜 간다
- 소품끼리도 뭉치지 않게 서로 거리를 둔다
- 마을 한가운데는 모이모가 빽빽해 어차피 안 보이므로 성기게 깔린다

수·크기·진하기는 `src/world/model.ts` 의 `PROP_COUNT`, `PROP_BACK`,
`PROP_FRONT`, `PROP_BACK_SHARE` 에서 고친다.
